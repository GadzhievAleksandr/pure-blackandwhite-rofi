# Black and white theme for rofi
This is pure and simple theme for your rofi in black and white style. It has got some transparency effects? which you can regulate on .rasi files of rofi's config. Blur, transparensy and other effects not dependent on hyprland's config.

## Features
* Darkened transparent background
* White outline of the elements
* Lightweight

## Requirements
* Rofi
* Distro with hyprland

> I don't know about efficiency of this on BSPW, I3-WM or other WM.

## Installation
```
git clone https://github.com/GadzhievAleksandr/pure-blackandwhite-rofi
cd .config
mkdir rofi
cd
cd pure-blackandwhite-rofi
cp config.rasi ~/.config/rofi
cp blackwiterofi.rasi ~/.config/rofi
```
